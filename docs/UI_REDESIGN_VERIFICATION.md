# Browser redesign verification — 2026-10-19

## Specification audit and scope

The explicitly requested redesign supersedes the older phase authorization limit in AGENTS.md for this work only. The handoff and standalone HTML were inspected before coding; the prototype supplies visual/interaction direction, not production data, APIs or reusable source. REQUIREMENTS.md and IMPLEMENTATION_PLAN.md were reviewed alongside browser, security, persistence and delivery sources/docs.

The starting repository already shipped authenticated plain embedded browser assets, exact matching, bounded event/execution history, secret edit DTOs, source-generated JSON, revision conflicts and session/polling cancellation. It also already shipped schema 3 per-webhook TLS opt-in, separate strict/unverified HttpClientFactory pools and real ephemeral HTTPS certificate tests. Those mechanisms are retained rather than duplicated.

Discrepancies addressed: no Overview, no event search, small one-column editor, event details unavailable alongside rule editing, mandatory secret-operation dropdowns, raw header JSON editing, local-only URL masking without persistent URL classification, and focus/redraw disruption outside the existing text-selection guard. Existing hover/focus field help needed explicit touch disclosure. No ONVIF API/library, matcher, queue, dispatcher, retry, network-address policy, deployment or dependency change is required.

## Implementation and contracts

Overview explicitly describes its counts and recent results as bounded transient process snapshots. Cameras retain every operation and distinguish reachability/subscription state. Rules show WHEN/THEN mappings, enablement and current/completed execution diagnostics. Event Explorer searches retained observations without changing history admission, including false/unmatched/Initialized/Deleted/truncated content.

The large responsive editor provides General/WHEN/THEN sections and Advanced matching & delivery. Active advanced settings open their section. Persistent desktop reference and a phone View event/Hide event disclosure preserve the form and actual complete selected notification. Fields enumerate Source/Data/Key entries with indexes; only complete scalar Source/Data values fill conditions, with replacement confirmation and comparison preservation. Raw JSON is complete retained inert text, with copy support; no sample event is substituted. Empty and truncated references are explicit. Mobile uses one editor scroll surface and reachable actions. Modal focus handling, field associations, disclosure state, keyboard help and Escape behavior are preserved/extended.

Unchanged secrets preserve, Edit replaces, confirmed Clear removes optional values, and Undo reverses pending changes. No stored credentials, headers, bodies or sensitive URLs are loaded into form values. Close/cancel/logout explicitly wipe input values before detaching nodes and release the submit closure. Header rows replace the entire write-only collection; they cannot patch unread stored rows. POST replacement bodies are validated as literal JSON.

Schema 4 transactionally adds UrlSensitive with DEFAULT 1 and a boolean constraint. Existing data and old API callers remain sensitive. New browser rules explicitly default visible; only authenticated reads of those rules contain PublicUrl. Omission preserves existing classification. Sensitive-to-visible requires replacement/re-entry; Preserve cannot reveal an existing secret and rejection leaves revision/configuration unchanged. Visible-to-sensitive can preserve the address but cannot revoke copies previously disclosed while visible. All other action secrets remain write-only. Storage remains recoverable plaintext protected by existing permissions, not encryption.

The existing TLS option stays default off, scoped to opted-in rule delivery/manual tests, with separate pools, strict camera transport, disabled redirects/proxies and existing address/deadline/retry bounds. No global callback or new transport bypass is added.

Polling keeps only one latest pending snapshot. Editing, inspection, active search input and text selections defer screen redraw while polling and connection/session handling continue. Button focus and page scroll are restored during background updates. Actions retain the revision of the displayed configuration; the editor retains its opening revision. Selection resume waits for the pointer/click action to complete. Logout/expiry still cancel requests and clear all protected editor/reference/snapshot state immediately.

## Direct masked-field editing follow-up

The later user instruction supersedes the handoff's Edit/Undo/Clear controls. Saved values now show a fixed editable mask. Leaving it unchanged maps to Preserve; typing maps to Replace; deleting the mask maps to Clear on Save. The first input removes the entire mask, including when editing from its middle.
